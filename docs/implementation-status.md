## Software verification

- Polymind: root `just verify` passes Biome, TypeScript, **562 tests across 50 files**, **84 Match tests including three worker contracts** and both application/package builds. The imported baseline was 515 tests across 44 files. A pre-existing rehearsal fixture depended on a 550 ms generation window; its test-only admission cadence now leaves reliable headroom, with the production interval separately asserted.
- Chromium: operator sign-in → session/round → mobile join → autosave/confirm → reload → freeze → analysis → explicit projection reveal passes. Visual screenshots checked at 390 px mobile and 1920 × 1080 projection. The typecheck also covers the browser regression fixtures; plain browser JavaScript is exercised by VM and Chromium tests.
- Continuous voice: 140 identities, long revisions, explicit model start, pause/end, saved-prefix recovery and independent subsequent round tested with a model double. New runs use complete source presentation; frozen old configurations remain unchanged.
- HTTP/storage: [140-client evidence](verification/polymind-140.json) and [180-client overload evidence](verification/polymind-180-overload.json). Each trial acknowledged 2,800 revisions, checked duplicate retries, reconnected 20%, rejoined with known cookies and verified all acknowledgements after restart. TCP setup is warmed in batches; the measurement stresses simultaneous requests, not 140 new TCP handshakes.
- Audio: 140 synthetic PCM-shaped uploads through the queue (about 269 MB), concurrency four; owner/round isolation, duplicate IDs, simultaneous quota enforcement, interruption, timeout/retry, changed-file integrity and deletion retry tests. This is not an HTTP/device/audio-quality benchmark.
- Backup: six synthetic tests preserve legacy IDs/hashes/journal bytes and verify SQLite/WAL, nested worker/audio files, checksums, restore integrity, locks and corruption/path rejection. Original source data is untouched.
- Match: [history-preserving import](migration/match.md) into `packages/match`; one uv project/lockfile/environment, 84 tests including installed-package schema/subprocess/restart/CLI-asset contracts pass. The same three contracts pass inside the production image without networking. The wheel checksum test was removed with the vendored wheel. Historical supplied-vector allocation timings were 1.891 s at 140, 2.697 s at 139 with a reviewed trio, and 3.260 s at 180. Embedding/provider time is excluded.
- Puck: 21 unit tests, five browser tests and real WebSocket scale trials pass. p95 round latency was 53 ms at 140 in its synthetic local test. Its final Linux/arm64 image runs as UID 1000 and passes health and two-client WebSocket checks. The production image is 481 MB, with development dependencies excluded.
- Flight: 98 Python tests, three JavaScript suites, sustained 140-client trial and non-root Linux/arm64 container smoke pass. p95 input RTT was 26.46 ms; batch-to-bridge propagation was 102.36 ms.
- Hub: four HTTP/revision/restart tests, mobile/operator browser transitions, non-root container health and durable restart pass.
- Previous Polymind container: Linux/arm64, image `sha256:8e33846ffe6460ae0cb4c07e5f24166247908d33b660b53c6149cea426a850c2`. The digest-pinned Node 26.13.0, Python 3.12.13 and uv 0.11.28 runtime passes health checks as UID 10001, with data at `/data/polymind` and its sibling writer lock inside the writable `/data` volume. That report records source hashes for its earlier candidate; it does not identify the current monorepo build. Four packaged Match contract checks, three acknowledged synthetic contributions surviving restart with identity and frozen snapshot intact, second-writer rejection, and packaged backup/isolated SQLite restoration pass. This verifies a local image, not a Coolify deployment, public TLS or physical phones.
