What do I run from here?

The Hub changes the invitation. It does not start or stop activities.

Polymind and Collective Voice
In the relevant session’s operator page, start or resume the activity, then end it there. For Polymind, close writing, analyse, review and release matching there. Keep any projection open separately.
Puck
In the browser that created the room: set the question and options, then start or cancel the round.
Flight simulator
Before the show, load the approach, connect the bridge and leave FlightGear paused. Recheck readiness before giving the cue. Participants join through the invitation; release phone controls before unpausing FlightGear locally. Connection loss does not pause the flight. Simulator readiness is not checked here.
In-person activity or a pause
Show the room’s instruction here. Participants already inside another app need to return to the Hub.

Advanced: participant link

Paste the participant link, or just its path (for example /?session=…). A full link chooses its own website. You don’t need to type https://. Never use an operator or projection link.

Website missing? Ask the person managing deployment to add its verified address to the Hub’s allowed websites.
